# Bundled fonts

## Twemoji.Mozilla.ttf

Twitter's emoji artwork, built as a COLRv0 font by
[mozilla/twemoji-colr](https://github.com/mozilla/twemoji-colr).

Bundled so Thrace renders emoji consistently across systems.

- Artwork: Twemoji, © Twitter/X, **CC-BY 4.0**
- Font build: mozilla/twemoji-colr, **Apache-2.0**

Attribution is required by CC-BY 4.0 and is provided here and in the
application's settings panel.

The system's `NotoColorEmoji` is still used as a fallback for emoji Twemoji
does not cover (it is pinned to an older Unicode revision).
